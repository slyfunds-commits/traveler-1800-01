One sentence of at most 200 characters explaining the modern internet to a
time traveler from 1800, for make.fun's "One Sentence for a Traveler from
1800" bounty ($2, top places paid). Pure Python stdlib — no dependencies.

The sentence, built only from things a person from 1800 already knows:

> It is an inn where every traveler in the world sits at one table, swapping
> letters, pictures and songs without ever leaving home.

`main.py` writes the sentence to `/output/entry.txt` and asserts the
1–200 character gate, byte-verifying what it wrote.
